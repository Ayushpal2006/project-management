# Talking-head videos

**Status: planned.** The user will add talking-head videos later. This file holds the rules agreed so far; extend it when the format and tools are chosen.

## Rules already decided

- Faces follow `skilled-brains-face-identity`. For any AI-generated or AI-lip-synced talking head, the person's real voice and face must be used only with their consent, the face must pass the resemblance check, and the user must approve before anything is published.
- Framing: eyes on the upper phi line (`skilled-brains-golden-ratio`), clear of reel/short UI zones (`skilled-brains-safe-zones`).
- Two framings, wide and about 1.3x tight, cutting between them on sentence boundaries (from `skilled-brains-reference-look`).
- Captions, hero words and pacing follow `skilled-brains-reference-look` section 1; house rules in `skilled-brains-motion-style` win.

Render in the cloud, not on the user's Mac; copy to the Mac only when the user says so.
