# People

One folder per team member who appears on screen. `identity.md` is committed; `photos/` and `grid/` are local only while the repo is public. Rules and the grid layout: `skills/skilled-brains-face-identity/SKILL.md`.

To add someone: copy `_template/` to a new folder named with their slug, fill in `identity.md`, put photos in `photos/`, and add them to the team table in `brand/BRAND_BRIEF.md`.
